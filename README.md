# Cyclistic Bike-Share Case Study

## Overview
This project analyzes 140k+ Cyclistic bike-share trips in Chicago to identify trends between casual riders and annual members. The goal is to support marketing strategies that convert casual riders to annual members.

## Business Questions
1. How do annual members and casual riders use Cyclistic bikes differently?
2. Why would casual riders buy annual memberships?
3. How can digital media influence casual riders to become members?

## Dataset
- Single CSV file with 140k+ bike trips
- Columns: ride_id, rideable_type, start/end times, start/end stations, latitude/longitude, rider type

## Analysis
- Ride lengths, usage patterns by day, hour, month  
- Bike type preferences  
- Geographic hotspots  
- Visualizations: 11+ charts including bar, line, boxplot, scatter, heatmap, and geographic maps

## Tools
- Python (pandas, seaborn, matplotlib, folium)
- Jupyter Notebook for interactive analysis

## Key Insights
- Casual riders take longer, weekend-centered rides  
- Members ride consistently for commuting  
- Electric bikes attract casual riders  
- Downtown and parks are high-potential areas for conversion campaigns

## Recommendations
1. Target casual riders on weekends with digital campaigns  
2. Promote annual memberships for users of electric bikes  
3. Optimize station placement and marketing near high-density zones

## How to Run
1. Clone this repo
2. Install Python dependencies: `pip install pandas matplotlib seaborn folium`
3. Open Jupyter Notebook and run all cells
